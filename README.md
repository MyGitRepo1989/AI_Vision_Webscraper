# AI_Vision_Webscraper
Automation Pipeline to Collect Data 

Source - Links of News Stories 

Method - Web Scraping using Vision, OCR Reader and LLM Summarizer

1 - Take Screenshots of Web Pages

2 - Extract Text with OCR

3 - Use LLM to summerize text, extract names, sources, emotions etc

4 - Use LLM to extract Topics

5 - Save Data
